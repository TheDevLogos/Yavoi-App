# Textos de ficha para tiendas

Los siguientes textos están listos para pegar como borrador. Antes de enviarlos
como declaración, confirmar que cada función se mantiene activa en la versión
que se subirá a revisión.

## Google Play — Yavoi!

| Campo | Texto |
| --- | --- |
| Nombre | `Yavoi!` |
| Descripción breve | `Pide viajes locales con tarifa clara, seguimiento y seguridad.` |
| Categoría | Viajes y guías locales |
| Correo de soporte | `admin.yavoi@gmail.com` |
| Política de privacidad | `https://yavoi-app.vercel.app/privacidad` |
| Eliminación de cuenta | `https://yavoi-app.vercel.app/eliminar-cuenta` |

### Descripción completa

```text
Yavoi! te conecta con viajes locales de forma clara y sencilla.

Consulta una tarifa antes de solicitar, elige el servicio que necesitas y sigue
el estado de tu viaje desde la aplicación. Guarda destinos frecuentes para pedir
más rápido y revisa cada servicio desde Mis viajes.

Con Yavoi! puedes:
• Buscar direcciones y destinos frecuentes.
• Conocer la tarifa estimada y cualquier ajuste autorizado.
• Ver la información del conductor y de la unidad asignada.
• Dar seguimiento a tu viaje y usar las opciones de ayuda durante el servicio.
• Consultar tu historial, comprobantes, recompensas y preferencias.
• Reportar un incidente o solicitar soporte desde el detalle del viaje.

La disponibilidad de servicios puede variar según la zona, los conductores
conectados y las condiciones operativas. Algunas funciones de pago electrónico
se habilitan cuando estén disponibles en tu zona.
```

## Google Play — Yavoi! Drive

| Campo | Texto |
| --- | --- |
| Nombre | `Yavoi! Drive` |
| Descripción breve | `Recibe viajes, navega y consulta tus ganancias con Yavoi! Drive.` |
| Categoría | Mapas y navegación |
| Correo de soporte | `admin.yavoi@gmail.com` |
| Política de privacidad | `https://yavoi-app.vercel.app/privacidad` |
| Eliminación de cuenta | `https://yavoi-app.vercel.app/eliminar-cuenta` |

### Descripción completa

```text
Yavoi! Drive es la aplicación para conductores autorizados de Yavoi!.

Conéctate cuando estés listo para conducir, recibe solicitudes de viaje y usa
la navegación integrada para llegar a la recolección y al destino. Consulta los
detalles necesarios para completar cada servicio y revisa el resumen de tus
ganancias.

Con Yavoi! Drive puedes:
• Activar o desactivar tu disponibilidad de forma manual.
• Recibir y aceptar solicitudes con información esencial del viaje.
• Navegar a la recolección y al destino dentro de la experiencia de Yavoi!.
• Avisar llegada, iniciar y finalizar servicios.
• Registrar cobros en efectivo y consultar el detalle de cada viaje.
• Revisar ingresos, billetera, comisiones, retenciones, incentivos y retiros.
• Mantener tus documentos y datos de conductor listos para revisión de Operaciones.

El uso de Yavoi! Drive requiere autorización previa de Operaciones. La
recepción de solicitudes depende de tu estado de disponibilidad, ubicación y
condiciones operativas.
```

| Categoría secundaria | Navegación | Finanzas |
| URL de soporte | `https://yavoi-app.vercel.app/privacidad` | `https://yavoi-app.vercel.app/privacidad` |
| URL de marketing | `https://yavoi-app.vercel.app/` | `https://yavoi-app.vercel.app/` |

No declarar pagos electrónicos, ubicación en segundo plano ni notificaciones
persistentes como funciones activas hasta validarlas con las cuentas y
credenciales productivas correspondientes.
